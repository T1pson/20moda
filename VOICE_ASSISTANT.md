# Assistive Voice Control

Десктопный модуль `voice_assistant.py` добавляет голосовое управление для людей
с ограниченными возможностями. Он слушает короткие слова или цифры и
нажимает нужные клавиши в выбранных играх и приложениях.

## Возможности
- **Персональные бинды**: слова вроде `1`, `2`, «прыжок» или любые другие,
  закреплённые за клавишами.
- **Профили приложений**: работает только в указанных играх/программах или,
  при желании, во всех сразу.
- **Минимальная задержка**: базовая задержка настраивается вплоть до нуля для
  моментальной реакции.
- **Умная работа с микрофоном**: автоподстройка под шум, выбор устройства,
  переключение мониторинга и сайдтона.
- **Темы интерфейса**: светлая, тёмная или системная — настройка хранится в
  конфиге и может использоваться в UI-клиенте.
- **Режим симуляции**: можно протестировать бинды без микрофона, подав список
  фраз через CLI.

## Быстрый старт
1. Установите дополнительные зависимости (микрофон требует `pyaudio`):
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите в режиме симуляции и убедитесь, что нажатия обрабатываются:
   ```bash
   python voice_assistant.py --simulate 1 2 прыжок
   ```
   В консоли будет показана обработка фраз; реальные нажатия выполняются через
   `pynput`.
3. Для постоянного прослушивания микрофона и автокалибровки шума:
   ```bash
   python voice_assistant.py --app "My Game"
   ```

## Конфигурация
Все настройки сохраняются в `voice_assistant.json` рядом со скриптом.

- **theme**: `light` | `dark` | `system` — влияет на визуальный клиент.
- **base_delay_ms**: задержка перед нажатием клавиши (0 для мгновенного
  отклика).
- **listen_everywhere**: если `true`, глобальные бинды работают во всех
  приложениях.
- **microphone**: параметры устройства (`device_index`, чувствительность,
  автогейн, длительность калибровки шума, мониторинг и сайдтон).
- **apps**: список профилей с набором `commands`, где у каждого указаны
  `phrase`, `key`, `hold_ms`, `enabled`, `allow_everywhere` и `hint`.

Конфиг создаётся автоматически при первом запуске и может редактироваться
вручную или через будущий графический интерфейс/трей-меню.
